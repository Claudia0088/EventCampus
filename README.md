# EventCampus

## Présentation

EventCampus est une application web de gestion d'événements étudiants.

L'objectif est de permettre aux étudiants de créer, consulter et rejoindre des événements tout en facilitant leur gestion et leur modération.

## Équipe

Projet réalisé par une équipe de 3 étudiants.

## Technologies

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- Maven
- MySQL
- SQL
- JUnit
- Mockito
- Git
- GitHub

## Fonctionnalités principales

- Création de compte et connexion
- Création d'événements
- Consultation des événements
- Recherche et filtres
- Inscription aux événements
- Gestion des participants
- QR Code pour la présence
- Système de modération
- Historique des événements
- Espace personnel

## Organisation du projet

- `frontend/` : partie interface utilisateur
- `backend/` : partie serveur et API
