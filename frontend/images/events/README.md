# Illustrations des événements

Ces huit illustrations SVG ont été dessinées spécialement pour EventCampus, sans photographie, police embarquée, script ou ressource tierce. Elles peuvent être utilisées et modifiées dans ce projet. Aucun crédit tiers requis.

Format : 800 × 500, couleurs issues des CSS existants. Le SVG est conservé pour sa netteté et son faible poids, plutôt qu’une conversion WebP.

Les fichiers sont associés aux huit événements publiés après confirmation de l’utilisateur. Les chemins MySQL suivent le format `/frontend/images/events/nom.svg`. Le résolveur partagé `frontend/js/event-images.js` adapte ces chemins à Live Server et à WAMP. Les autres colonnes, dont `updated_at`, ont été préservées.
